# Política de segurança

## Versões suportadas

O Pingo ainda está em desenvolvimento. Correções de segurança são aplicadas na versão mais recente da branch `main`.

## Relatar uma vulnerabilidade

Não publique vulnerabilidades como issues abertas. Use um [Security Advisory privado](https://github.com/PedroVinicins/pingo-financas/security/advisories/new) e informe:

- versão afetada;
- passos para reproduzir;
- impacto possível;
- sugestão de correção, se houver.

Não envie dados financeiros reais durante o relato.
